# Customer Churn Prediction

## 🧠 Problem Statement
Telecom companies lose revenue when customers leave (churn). Predicting churn helps retain customers and increase profits.

## 📦 Dataset
Used IBM Telco Customer Churn dataset with real customer features such as tenure, contract type, payment method, and service usage.

## 🧰 Approach
1. Data Loading & EDA
2. Data Cleaning & Preprocessing
3. Model Training (Logistic Regression & Random Forest)
4. Model Validation with Cross-Validation
5. Feature Importance & Business Insights

## 📊 Key Insights
- Month-to-month contracts are more likely to churn
- Customers with shorter tenure show higher churn
- Certain payment methods and service additions influence churn likelihood

## 🧪 Results
Models were evaluated using accuracy, classification metrics, and ROC-AUC to ensure reliable performance.

## 🛠️ Tech Stack
Python, Pandas, Scikit-learn, Matplotlib
